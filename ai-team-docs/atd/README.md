# Решения о работе AI team (ATD)

Решения о том, как AI team работает в этом проекте (DEC-0049, DEC-0091 AI kit). Решения о продукте — ADR в `docs/adr/` (`adr_dir` в project overlay): они переживут удаление AI kit, ATD — нет. Номера у ATD свои: `ATD-0001`, `ATD-0002`, …

- **Решение** — файл `ATD-NNNN-<slug>.md`: «как решено сейчас». Шаблоны — `templates/decisions/` AI kit (полный — если в разговоре были варианты, иначе минимум).
- **История** — `history/<тот же файл>`: записи «дата · автор · принято | изменено | отменено», новые сверху; в записи «изменено» — почему и полный прежний текст.
- **Номер один навсегда.** Решение поменялось — правится тот же файл и запись сверху в истории; другой вопрос — следующий номер (`ai-team adr-next --atd`). Отменённое остаётся со своим номером, статус «отменён».
- **Принимает человек:** PR с изменениями здесь вливается только с его одобрением (spec/13 AI kit).

Индекс ниже собирает скрипт — `ai-team adr-index` (или `node .github/ai-team/process-guard.mjs adr-index --write`); руками не править, конфликт в git не сводить, а пересобрать.
